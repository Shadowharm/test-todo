# Проверка перед сдачей

Дата: 6 ноября 2026 года. Среда локальных прогонов: macOS arm64, Node 22.18.0.

## Результаты

- `npm run check`: форматирование, 20 тестов Vitest, строгая проверка TypeScript и production-сборка — успешно.
- `npm run test:e2e`: 65 сценариев — успешно. Матрица: Chromium, Firefox, WebKit, WebKit с мобильными ширинами 320 и 375 px.
- Чистый локальный клон коммита `469ef96`: `npm ci` и `npm run check` — успешно, установка без обнаруженных npm-уязвимостей.
- Design QA на заполненной странице при 320 и 1440 px: 0 блокирующих проблем, 0 высоких замечаний. Проверены контраст, размеры целей, отсутствие переполнения и обход фокуса клавиатурой. Это автоматическая проверка измеримых свойств, не заявление о полной доступности для всех экранных дикторов.
- Состояния списка, форм и погоды покрыты тестами: пустой список, ошибки валидации и хранения, ожидание погоды, ошибка запроса, повтор и успешное сохранение.
- В отдельном просмотре production-сборки подтверждены сообщение о названии из пробелов, удержание фокуса в диалоге и возврат к кнопке открытия.

Автотесты используют изолированные данные и подменяют ответы погодных сервисов. Реальная загрузка погоды дополнительно наблюдалась при ручном просмотре. Строго одновременные конфликтующие записи двух вкладок не входят в гарантии localStorage; последовательные изменения проверены.

Проект Vercel подключён к GitHub-репозиторию и автоматически публикует `main`. Production-домен: [test-todo-lyart-psi.vercel.app](https://test-todo-lyart-psi.vercel.app/). Настройки Pages не изменялись; сборка использует корневые пути.

[Результаты CI](https://github.com/Shadowharm/test-todo/actions) доступны после отправки изменений. Локальные результаты выше не подменяют статус удалённого прогона.

Записана демонстрация продолжительностью **63 секунды**: `artifacts/dayline-demo.mp4`. Исходная запись — `artifacts/dayline-demo.webm`, снимки — `artifacts/desktop.png` и `artifacts/mobile.png`. Эти файлы остаются локальными и не входят в Git. Повторная запись: `npm run preview`, затем `npm run demo` в другом терминале.
