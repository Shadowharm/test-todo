# День за днём

Небольшой планировщик задач на React и Vite. Задачи сохраняются в localStorage браузера.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Для сборки используйте `npm run build`, для просмотра сборки — `npm run preview`.

Выберите день в календаре, добавьте задачу с датой и временем, отметьте её выполненной или удалите. Данные хранятся только в текущем браузере и не синхронизируются между устройствами.
